# docs/

Supporting documents. **None of these describe the current, working codebase** —
for that, see the [top-level README](../README.md).

They live here rather than in the repository root so that the root reflects
what actually exists.

## `proposals/` — designs for unbuilt work

| Document | What it is |
|---|---|
| [CRYPTO_FRONTEND_PLAN.md](proposals/CRYPTO_FRONTEND_PLAN.md) | Implementation plan for a web frontend and crypto exchange integration |
| [USER_GUIDE.md](proposals/USER_GUIDE.md) | The same proposed platform written up as an end-user guide |

Neither has been started. There is no frontend, backend API, database,
WebSocket layer, or crypto integration in this repository. The user guide in
particular reads as operating instructions for a live product — it is not one.
